# Готэм: Дела стажёра

Браузерная детективная игра. Ты — новый Робин, и Бэтмен берёт тебя на стажировку: вместе вы разбираете странные преступления Готэма.

## Как играть

1. Открой `index.html` в браузере (сборка и сервер не нужны).
2. На заставке выбери папку с делом.
3. На каждом месте преступления нажимай на предметы. Кнопка **«Режим детектива»** подсвечивает всё, что можно осмотреть.
4. Каждая улика — загадка. Реши её, и вывод попадёт в блокнот.
5. Если упёрся, нажми **«Спросить Бэтмена»**. Подсказок три, от намёка до разбора, но они стоят очков.

## Очки

| Загадок решено с подсказкой | Очки |
| --- | --- |
| ни одной | 100 |
| 1–3 | 75 |
| 4–10 (около половины) | 50 |
| 11–16 (почти все или все) | 25 |

Считаются загадки, а не нажатия: три подсказки к одной улике — это одна загадка «с помощью».

## Дело №1. «Мёртвые даты»

Три тела за три месяца, у каждого на лбу чернилами выведена дата. Четыре места преступления, по четыре улики на каждом. Разгадка здесь не раскрывается.

## Как устроен проект

| Файл | Что внутри |
| --- | --- |
| `index.html` | разметка трёх экранов: заставка, дело, пещера |
| `css/style.css` | пиксельный и комиксный стили |
| `js/pixel.js` | пиксельная графика на canvas: дорога, бэтмобиль, пещера, переход |
| `js/art.js` | комиксные сцены и портрет Бэтмена (SVG, нарисованы кодом) |
| `js/case1.js` | сюжет, улики, загадки, ответы и подсказки первого дела |
| `js/game.js` | движок: сцены, проверка ответов, подсказки, подсчёт очков |

Чтобы добавить новое дело, нужен файл по образцу `js/case1.js` и сцены для него в `js/art.js`.

Картинок и звуков в репозитории нет: вся графика рисуется кодом.
