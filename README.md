# Готэм: Дела стажёра

Браузерная детективная игра. Ты — новый Робин, и Бэтмен берёт тебя на стажировку: вместе вы разбираете странные преступления Готэма.

## Как играть

1. Открой `index.html` в браузере (сборка и сервер не нужны).
2. На заставке выбери папку с делом, потом сложность.
3. На каждом месте преступления нажимай на предметы. Кнопка **«Режим детектива»** подсвечивает всё, что можно осмотреть.
   Между местами можно переходить в любом порядке по **карте дела** под заголовком. Логово открывается, когда собраны все улики.
4. Каждая улика — загадка. Реши её, и вывод попадёт в блокнот.
5. Если упёрся, нажми **«Спросить Бэтмена»**. Подсказок три, от намёка до разбора, но они стоят очков.

## Сложность

| Уровень | Что меняется |
| --- | --- |
| Лёгкая | К загадкам приложен «Справочник стажёра» (алфавит по номерам, перевод, правила), часть ответов выбирается из вариантов, в механизмах есть послабления |
| Средняя | Справочник есть, но отвечать нужно самому |
| Сложная | Только улики: всё нужное есть на месте преступления, но без пояснений |

## Настройки, музыка и звук

Кнопка **⚙** в правом верхнем углу открывает настройки прямо во время игры: громкость музыки и звуков, яркость и контраст картинки, дождь на сценах, спокойный режим без лишней анимации, скорость появления текста, крупный текст и сложность. Настройки запоминаются в браузере.

Музыка и звуки синтезируются в браузере (Web Audio), файлов нет: погоня под дождём в заставке, нуар с пианино и громом в первом деле, механический вальс музыкальной шкатулки во втором, восьмибитная фанфара в пещере. Браузеры разрешают звук только после первого нажатия, поэтому музыка начинается с первого клика.

## Загадки

Кроме вопросов с текстовым ответом, в игре есть механика: кодовые барабаны, сейфовый лимб, шестерни, шифровальный диск, часы со стрелками, зеркальце для зеркального текста, штриховка карандашом, расстановка предметов по местам, настройка волны, поиск отличий на двух фотографиях, сравнение отпечатков пальцев с поворотом, раскладка улик по двум почеркам.

## Очки

| Загадок решено с подсказкой | Очки |
| --- | --- |
| ни одной | 100 |
| 1–3 | 75 |
| от 4 до 60% загадок | 50 |
| больше 60% загадок | 25 |

Считаются загадки, а не нажатия: три подсказки к одной улике — это одна загадка «с помощью». Сложность на очки не влияет, но показывается рядом с результатом.

## Дела

- **№1. «Мёртвые даты».** Три тела за три месяца, у каждого на лбу чернилами выведена дата.
- **№2. «Безумное чаепитие».** Три уважаемых человека грабят сами себя и засыпают за накрытым чайным столом.
- **№3. «Два почерка».** Три тела за три ночи, и на каждом месте как будто работали две разные руки. В этом деле есть архив беглецов из Аркхема: следы без загадок (ДНК, обувь, привычки) нужно сопоставить с восемью досье, а бэт-компьютер скажет только, сколько записей верны. Логово открывается после проверки архива.

### Сюжетная кампания

Три дела выше — учебные. Когда все три пройдены, на заставке открывается папка **сюжетной кампании**: дела в ней связаны одним сюжетом и одним главным злодеем и разбиты на главы.

**Глава I. «Пациенты доктора Стренджа».** Главный психиатр Аркхема Хьюго Стрендж тайно выпустил из изолятора шестерых опасных пациентов, и каждый получил свой список преступлений. В каждом списке — Брюс Уэйн.

- **Дело 1. «Белое пламя».** Пожары на имуществе Уэйна и скелет в белом огне. В деле собраны все механики учебных дел, есть архив беглецов, а финал — новый **допрос**: подозреваемый лжёт, а Робин опровергает каждую ложь уликой из блокнота. Дела 2–6 главы засекречены и выйдут позже.

Для проверки кампанию можно открыть без прохождения учебных дел: добавь к адресу `?unlock`.

В каждом деле четыре места преступления, по четыре загадки на каждом (в третьем деле — ещё по два следа для архива). Разгадки здесь не раскрываются.

## Как устроен проект

| Файл | Что внутри |
| --- | --- |
| `index.html` | разметка трёх экранов: заставка, дело, пещера |
| `css/style.css` | пиксельный и комиксный стили, виджеты загадок |
| `js/pixel.js` | пиксельная графика на canvas: дорога, бэт-сигнал, бэтмобиль, пещера, переход |
| `js/audio.js` | синтезатор музыки и звуков |
| `js/art.js`, `js/art3.js`, `js/art4.js` | комиксные сцены и портреты (SVG, нарисованы кодом) |
| `js/case1.js` … `js/case3.js` | сюжет, улики, загадки, ответы и подсказки учебных дел |
| `js/camp1.js` | глава I кампании: список дел главы и дело «Белое пламя» с допросом |
| `js/game.js` | движок: карта дела, типы загадок, сложность, подсказки, настройки, подсчёт очков |

Чтобы добавить новое дело, нужен файл по образцу `js/case2.js`, сцены для него в `js/art.js` и строчка в списке `CASES` в `js/game.js`. Варианты улики для разных уровней задаются полями `easy`, `medium`, `hard`, справочник — полями `aid` и `aidEasy`.

Картинок и звуков в репозитории нет: вся графика рисуется кодом.
